Research & Machine Learning

2D Generative Models — DDPM, DDIM, GAN, MeanFlow

Four generative model families implemented from scratch in PyTorch and trained on 2D synthetic distributions. Rather than comparing samples by eye, models are scored with optimal-transport metrics — 2-Wasserstein distance and energy distance — which makes the trade-off between sample quality and sampling cost measurable: DDIM shortens the reverse trajectory, and MeanFlow collapses it to a single network evaluation.

SMART-D — LLM-Guided Multi-Agent Reinforcement Learning

A cooperative multi-agent PPO framework in which a frozen LLM acts as a training-time macro-planner, proposing high-level subgoals to break the exploration deadlock in sparse-reward coordination tasks. A coupled reward-shaping and KL self-distillation schedule internalises that guidance into a single teacher/student network, so the LLM is removed entirely at deployment — zero inference latency. On Overcooked-AI it escapes the coordination collapse that standard PPO falls into on Forced Coordination.

Scene-Specialized DQN for Multi-Level Generalization

A mixture-of-experts agent for the LevDoom Seek and Slay benchmark, where one policy must hold up across five levels with different maps, enemies and visual styles. Instead of forcing a single network to generalise, five level-specialised Rainbow-Lite experts are routed by a learned scene classifier, locked in after three frames. Intrinsic motivation — RND plus a hashed episodic memory — is scaled per level and switched off where exploration is not the bottleneck.

Self-Supervised Medical Image Segmentation

Binary segmentation of grayscale medical images, built to isolate a single question: does the improvement come from the architecture, or from the initialisation? Adding a Transformer bottleneck to a U-Net moved validation Dice by 0.0004 — nothing. Pretraining the same architecture with SimCLR on the unlabelled images raised it by 2.9% and cut the validation-to-test generalisation gap by a factor of four. No external pretrained weights are used anywhere.

Go Rank Prediction as Ordinal Regression

Predicting a Go player's rank (1D–9D) from game records. Rank is ordered, so treating it as flat classification throws away structure and punishes near-misses as hard as gross errors — the model is trained with a CORAL ordinal-regression objective instead, over an ensemble stacking Transformer, BiLSTM and gradient-boosting predictors, with multi-view inference for stability on long games.

Micropayment System — SSL/TLS Client–Server Payment Platform

A secure micropayment platform in C++ and OpenSSL. Registration, login and balance queries run over TLS channels with generated and mutually inspected certificates; peer-to-peer transfers bypass the server entirely, with each client forking a child process to listen for encrypted transactions from peers behind a thread-pool server.

Bello — Social Meetup & Real-time Chat System

A full-stack platform for creating and joining physical meetups, with real-time private and group chat, a friend system and Google Maps location autocomplete. Built on a normalised PostgreSQL schema (4NF) behind a modular Flask backend covering auth, profiles, chat, friendship, meetings and admin, deployed serverless on Vercel.
